# Dock 增强重构

## 参考与边界

2026-10-29 阅读 Vorssaint 的 DockClickService、DockClickSupport、DockPreviewService、DockPreviewSupport、DockTileResolver、WindowEnumerator、WindowActivator 与 WindowPreviewProvider 后，依据其事件和生命周期机制为 MacKit 独立实现；不引入其整个服务依赖树，不复制其 GPL 源文件。MacKit 继续采用仓库原有许可证。

参考：https://github.com/vorssaint/vorssaint-utils/tree/main/Sources/Vorssaint/Services

实现对应：

- `DockEnhancementService`：单个可拦截事件 tap、权限与清洁模式暂停、锁屏暂停、Space 变化关闭面板、内存压力释放缓存。
- `DockHitTest`：Dock 方向和放大尺寸、可见 Dock 窗口所有权、AX 命中元素向上查找、URL 优先匹配、多实例图标配对、最后才使用唯一名称匹配。隐藏 Dock 和其他显示器上不在场的 Dock 不可命中。
- `DockClickController`：按下决定是否接管，抬起才提交；双击去抖、动画期间使用上次操作意图；超过 6pt 拖动阈值时标记并重放原始事件。原生 Dock 不接收已处理的半次点击。
- `DockWindowAccess`：目标应用 AX 查询及修改全部在串行后台队列执行，设置 AX 超时与枚举时间预算。合并 CG 与 AX 窗口，最小化后变为 AXDialog 的窗口仍保留。优先调用明确标识为 `miniaturizeAll:` 的菜单项，再按窗口补齐；不发送未经验证的键盘快捷键。
- `DockPreviewController`：200ms 首次悬停、100ms 应用间切换、220ms 离开延迟、16ms 合并指针事件且保留最后位置；进入面板前保留图标到面板的窄通道。面板先展示窗口条目，再逐张更新截图。截图和悬停任务均受取消/会话令牌保护。
- `DockThumbnailStore`：WindowServer 优先、ScreenCaptureKit 回退；全尺寸系统表面即时缩为自有位图再释放，缓存使用 PID+窗口 ID 键。最多 24 张、总成本目标 8 MB，90 秒过期，内存压力或功能停用时清空。只在面板打开时抓图，不增加后台预热或连续刷新。

本次没有加入 Vorssaint 的固定面板、拖拽窗口贴边、自定义 Dock 设置或全局 Space 快捷键接管；这些不属于本次 Dock 预览和点按最小化范围。

## 验证

纯逻辑测试覆盖原生点击保留、快速重复点击决策、动画期反向操作、拖动阈值、负坐标显示器布局、三侧 Dock 定位和悬停通道。

```sh
swift test --package-path Packages/MacKitCore --scratch-path build/CoreTests
scripts/build.sh Debug --signed
```

编译产物统一在项目 `build/` 下。真实桌面交互尚不能由上述测试确认，按以下顺序验收：

1. 完全退出旧版 MacKit，运行项目内新版本，确认辅助功能和屏幕录制授权。
2. Safari / Finder / Terminal 各打开至少两个窗口；悬停、沿通道进入面板并点击指定窗口。
3. 连续越过相邻 Dock 图标、快速离开并重新进入、移入面板后移出，检查不闪烁、不显示前一个应用的图像。
4. 点按当前应用图标收起窗口，再点按还原；测试双击与动画未结束时再次点按。
5. 拖动当前应用的图标重新排序；测试 Command/Option/Control 点按、右键以及后台应用点按，确认原生行为仍在。
6. 分别测试最小化、全屏、其他 Space、隐藏应用；全屏点按隐藏应用。系统没有可用的窗口图像时允许占位，但标题和选择应保留。
7. 将 Dock 改为左右侧、自动隐藏、放大；在负坐标/上下排列的副屏重复测试。Dock 不在场的屏幕边缘不得触发预览/最小化。
8. 关闭/暂停功能、锁屏再解锁，确认 tap 和缓存释放及恢复。

仅列出窗口不保证系统能为它提供可抓取图像。其他 Space 中缺失 AX 元素的窗口目前依赖应用激活和激活后 AX 重试；不通过合成 Space 导航强制移动桌面。该情形及全屏同应用多窗口需重点实测。

## 2026-10-29 窗口预览会话重做

固定采用窗口缩略图网格；100ms 最短显示延迟，在指针所在显示器上显示，统一按内建显示器比例计算列数，多行纵向滚动。每个窗口一项，全屏窗口保留，隐藏应用视为最小化，最小化项末尾排列，无窗口的运行中应用仍保留应用入口。Tab/Shift-Tab 和方向键选择，反引号限制到选中应用的窗口，⌘W 关闭窗口、⌘Q 请求退出应用、⌘M 最小化窗口；不提供 Esc 取消。关闭和退出不强制终止应用，不跳过应用自身的保存提示。

读取目录移出键盘事件回调；快速松开 Command 的确认意图在目录完成后处理。选择期间不清空缩略图、不移动或重建面板。每次会话重新读取窗口，并在可见期间每 900ms 检查删除已关闭条目。AX 成功回答的空数组不会再被 CG 旧表面填回；AX 不可用时仅接受仍在屏幕上且有标题的 CG 表面。完全黑色/透明截图不覆盖已缓存的有效预览。该保守策略下，AX 无法描述的其他 Space 窗口可能被排除，尚未实现 Vorssaint 的完整 Space 拓扑桥接与桌面导航机制。

切换器显示图像与 Dock 共用按需截图实现；单个切换器会话最多保留 24 张图像，离开会话释放展示数据，缓存有独立上限。Dock 预览也支持多行布局及窗口消失检查。

预览卡片左上角提供退出、关闭、最小化按钮，右下角提供最小化/全屏图标。切换器支持悬停选择；窗口操作后松开 Command 不自动重新激活该窗口。Dock 不再将条目截断为 8 个。

卡片标题区左侧为红色退出、蓝色关闭、黄色最小化按钮，禁用状态为灰色；右侧为右对齐标题/应用名，截图居中置于下方。外接竖屏也使用内建显示器的目标比例，仅按可用宽高约束尺寸。
