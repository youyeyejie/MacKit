# v0.4.0 手工验收

打开 `~/Applications/MacKit.app`。已完成签名构建、6 项核心测试和 6 项快捷键持久化检查。

## 软件设置

- 登录后启动下方不再显示状态与说明；显示位置的两个开关与它右对齐。
- 点击快捷键旁的清空按钮，应显示“未设置”，原组合立即失效。
- 分别清空唤起或清洁快捷键，另一项仍能正常触发。
- 同时清空后退出重开，仍为未设置；可用 Spotlight 或应用图标打开主面板。
- 点击未设置重新录制；重复组合和系统占用组合应拒绝；Esc 取消录制。
- 开启菜单栏后，四项依次为打开主面板、打开清洁模式、启用/关闭访达剪切、退出MacKit。
- 菜单“打开清洁模式”显示清洁页面；访达开关与页面开关同步。

## 页面

- 侧栏仅有设置、权限、关于，以及清洁、访达剪切两个工具。
- 关于显示实际版本 v0.4.0，权限和清洁页底部说明已删除。
- 权限页不再有卸载专用的完整磁盘访问入口。
- 访达页显示“使用 ⌘ X 剪切”、按键样式的剪切/粘贴/取消剪切说明，无当前状态卡片；剪切角标管理按钮靠右。

## 清洁

- 点击开始立即锁定；键盘、触控板、滚动和手势不穿透。
- 提示常驻；每次 Esc 点亮一个圆点，五次退出，其他键清空进度，长按不重复计数。
- 退出后输入恢复，亮度不变。系统保留的 Touch ID/电源操作不受应用控制。

## 访达

使用普通本地目录中的可丢弃文件验证。

- ⌘X 后源文件保留并显示无底橙色剪刀；⌘V 移动，Esc 取消剪切。
- 粘贴、取消、剪贴板覆盖后清除角标；⌘C 仍复制，文本输入不受文件剪切影响。
- 确认图标、列表、分栏视图；同名冲突交由访达处理。
- 如部分目录不显示，记录目录类型及其他访达扩展状态；不要自动关闭其他扩展。
