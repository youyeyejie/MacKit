# macOS 26 手工验收（开发预览 0.1）

当前验证环境：macOS 26.6.2 / Apple Silicon。程序已在此系统启动，核心逻辑 12 项自动化测试通过；以下交互项目交由用户实测。

## 打开与授权

预览应用位于 `build/DerivedData/Build/Products/Debug/MacKit.app`。可直接双击打开。源码工程是 `MacKit.xcodeproj`。

在 MacKit「设置」里点击「请求辅助功能授权」，然后在系统设置 → 隐私与安全性 → 辅助功能中开启 **MacKit**。完全退出再打开 MacKit，在设置里点「刷新状态」，应显示已授权。

测试期间保持此构建不变。临时签名的程序重新编译后，系统可能要求移除旧授权再重新添加。不要给未知应用或同名其他程序授权。

Finder 角标依赖有效开发团队签名、App Group 和扩展启用；当前临时签名预览预计显示“角标不可用”。登录启动也应等正式签名并放入 `/Applications` 后测试，当前失败不作为逻辑功能结论。

## A. 基础窗口（约 1 分钟）

- 打开后有一个 MacKit 窗口，无 Dock 图标和菜单栏状态图标。
- 清洁模式、Finder 剪切、应用卸载、设置四个页面可切换，内容不溢出。
- 关闭窗口后，用 Spotlight 再次打开 MacKit 或按 ⌃⌥⌘M，应该重新显示同一个控制窗口。
- 点击「退出 MacKit」后，后台进程结束。
- 在辅助功能未授权时，点开始清洁只显示授权提示，不黑屏、不锁输入。

## B. 清洁模式（先测这组）

首次建议只做短测试，不要立即开始擦拭。可先在终端运行以下退出兜底；它仅在 30 秒后结束 MacKit 进程，不改系统设置：

```sh
sleep 30; pkill -TERM -x MacKit
```

随后进入 MacKit：

1. 点「开始清洁」，倒计时 3 秒。倒计时内点「取消」应不锁定。
2. 再开始，松开键盘与触控板。内建屏幕变黑，开始显示提示，约 3 秒后隐藏；外接屏只出现锁定提示。
3. 输入字母、空格、回车及常用组合键，底下的应用不应收到输入。
4. 测试触控板移动、轻点、按压、双击、右键、双指滚动、拖拽。指针和底下窗口应不响应。
5. 单独测试三/四指切换桌面、Mission Control、显示桌面、缩放、旋转。记录所有穿透行为；这是当前重要待验证项。
6. 按 4 次 Esc 不应退出；第 5 次按下并释放后退出。相邻按键间隔小于 3 秒。
7. 再进入，长按 Esc 不能累计成 5 次；按 Esc 中途按其他键，再按 Esc 应重新计数。
8. 退出后键盘、触控板、指针均正常，屏幕亮度没有被改变。

扩展验证：全屏应用中进入、外接显示器、镜像模式、清洁中合盖/睡眠。唤醒后不应自动重锁。电源长按、Touch ID 等系统保留操作不在拦截承诺内。

若 Esc 未能正常解锁，等待上述退出兜底。不要用真实清洁过程代替短测试；先反馈失败时的操作顺序。

## C. Finder 剪切（使用临时文件，约 3 分钟）

在任意可写测试目录建 `Source` 和 `Target` 两个文件夹，放入两份无用文本文件。启用 MacKit「Finder 剪切」开关。

- 在 Source 选中文件，⌘X。文件此时仍在原处；MacKit 应显示待移动项目数。
- 到 Target 按 ⌘V。文件移到 Target，Source 中消失。Finder ⌘Z 应可撤销。
- 多选两份文件重复以上步骤。
- ⌘C 后 ⌘V 仍应复制，源文件保留。
- ⌘X 后在其他应用复制一段文字，再返回 Finder；旧待移动状态应被取消，不能意外移动旧文件。
- Finder 重命名文件时，用 ⌘X / ⌘V 操作部分文件名，应该是文本剪切粘贴。
- Finder 搜索框中 ⌘X / ⌘V 应正常处理文字。
- ⌘X 后在 Finder 文件区按 Esc，取消待移动，不改动源文件。
- 分别记录图标、列表、分栏、画廊视图和桌面选择的结果；不支持的 AX 焦点上下文会保留原生行为。
- 同名冲突应由 Finder 弹出提示；点取消后文件不应丢失，重试时重新 ⌘X。

当前临时签名版不要求显示角标。移动状态采用 10 分钟有效期；提交后显示“已交给 Finder”，不自行宣称传输完成。

## D. 应用卸载（先只扫描）

1. 选一个普通第三方应用，检查应用名称/Bundle ID、本体、关联文件、路径、分类、大小和扫描范围提示。
2. 点放大镜，在 Finder 中检查对应路径。不要在首次验收中卸载正在使用的真实应用。
3. 名称匹配、共享目录、后台服务、系统位置应不可勾选；配置和用户数据默认不勾选。
4. 更换勾选项，点「审阅并移到废纸篓」。确认窗口必须列出完整的目标路径；点「取消」不产生删除。
5. 测试拖入 `.app` 与文件选择器入口；扫描时点「停止」，应终止后续扫描，不执行删除。
6. 选择 MacKit 自身或 Apple 系统应用，应拒绝普通卸载。

如要验证真正移到废纸篓，可使用本项目已生成的可丢弃测试包：`build/Fixtures/MacKitSmoke.app`。它只含元数据和测试文字，没有可执行程序或用户数据。选择它，核对仅勾选测试包后确认；应在废纸篓中找到它并显示逐项结果。无需拿真实软件做删除测试。

## E. 后续签名后验收

- Finder 扩展启用后，待移动角标出现；取消、粘贴、剪贴板覆盖后清除；重启及过期不残留。
- 云盘/其他角标扩展共存测试。
- 从 `/Applications` 正式签名应用启用登录启动，注销或重启后静默运行，仍无 Dock/菜单栏图标。
- macOS 14、15、27 的窗口、输入权限、Finder 集成和卸载各跑一遍；26、27优先覆盖系统小版本更新。
