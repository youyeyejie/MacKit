# v0.6.0 手工验收

从 `~/Applications/MacKit.app` 打开。

## 访达剪切与音效

使用普通本地目录中的可丢弃文件测试。

1. 开启“使用 ⌘ X 剪切”和“剪切音效”，选中文件按 ⌘X，应听到一声短剪切音效；不显示角标。
2. 多选文件 ⌘X 应只响一次；⌘V 移动、Esc 取消都不播放音效。
3. 关闭音效，⌘X/⌘V 仍正常且无声；退出重开应保持关闭。
4. 重新开启后声音恢复。无文件选中、文本框剪切不会播放文件剪切音效。
5. 音效遵循系统输出音量及静音；快速重复剪切不会叠加多个播放器。
6. 权限页和访达页不再有角标、扩展管理或重载入口；安装包不含扩展，退出无角标进程。

## 其余回归

- 清洁模式立即锁定，提示“清洁模式”、闪光图标；外接屏圆角提示。
- 五次独立 Esc 退出，其他键清空计数，长按不重复累计。
- 快捷键录制、清空和重启持久化；Dock/菜单栏与登录启动开关保持原设置。
- ⌘C 仍为复制，访达文件名编辑及搜索框中的文本剪切不受影响。
