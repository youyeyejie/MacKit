# 实现与验证状态

版本：v0.4.0，日期：2026-10-28。

## 当前功能

- 清洁：立即锁定键盘和触控板，内建屏黑色覆盖，常驻五圆点提示，连续五次 Esc 退出。
- 访达剪切：⌘X 剪切、⌘V 粘贴、Esc 取消剪切；透明底橙色剪刀角标，扩大图案占比。
- 设置：登录后启动、Dock/菜单栏显示、可录制或清空的两个全局快捷键。开关统一右侧对齐。
- 权限：辅助功能及访达扩展，返回窗口自动更新。
- 关于：读取应用实际版本号，显示 v0.4.0。
- 菜单栏：打开主面板、打开清洁模式页面、启用/关闭访达剪切、退出MacKit；开关名称随功能状态更新。

应用卸载的页面、服务、扫描/权限重置/删除代码、模块标识、相关测试及工程引用均已移除。完整磁盘访问入口和权限数据库探测也已删除。不会删除用户此前生成的本地操作记录。

## 验证

- Xcode 27.1 / macOS 27 SDK / deployment 14.0：签名 Debug 构建成功。
- 6 项核心测试通过：Esc 状态、剪贴板所有权、角标过期和原子文件替换监听。
- 6 项隔离快捷键持久化检查通过：首次默认、分别清空、同时清空、重新录制和无效配置恢复。未更改用户快捷键配置。
- 主程序及扩展仍采用同一 Personal Team 的 Apple Development 证书。
- 0.3 用户已确认隔离其他扩展后显示角标，恢复后反馈似乎也正常；未继续变更其他扩展。

## 待人工验证

清空快捷键后立即失效、重启保持未设置、重新录制恢复；菜单栏项目及状态；右对齐布局；透明橙色剪刀的可见性。macOS 14、15、27 和 Intel 尚未实机验收。
