# 实现与验证状态

版本：v0.5.0，日期：2026-10-28。

## 当前功能

- 正常退出清空角标、释放监听，并仅暂停 MacKit 扩展；下一次启动恢复自身保存的暂停状态，不覆盖用户手动关闭的扩展。
- 实测：用户用 ⌘Q 退出后主进程与角标扩展进程均不存在，共享状态 ownerRunning=false 且无待移动文件；再次打开后主进程与扩展恢复，ownerRunning=true。
- 访达页提供检查角标、重载扩展。重载会停用自身、通知旧实例结束、重新发布状态后恢复；不操作其他应用扩展。
- 按用户选择仅保留原生角标，不添加浮层；多扩展同目录共存限制仍存在，不宣称已彻底解决系统冲突。
- 清洁覆盖层标题“清洁模式”、闪光图标；外接屏提示窗透明背景配圆角形状。
- 权限页访达扩展右侧显示状态圆点和管理按钮；设置卡片统一行高、间距及控件对齐。

- 清洁：立即锁定键盘和触控板，内建屏黑色覆盖，常驻五圆点提示，连续五次 Esc 退出。
- 访达剪切：⌘X 剪切、⌘V 粘贴、Esc 取消剪切；透明底橙色剪刀角标，扩大图案占比。
- 设置：登录后启动、Dock/菜单栏显示、可录制或清空的两个全局快捷键。开关统一右侧对齐。
- 权限：辅助功能及访达扩展，返回窗口自动更新。
- 关于：读取应用实际版本号，显示 v0.5.0。
- 菜单栏：打开主面板、打开清洁模式页面、启用/关闭访达剪切、退出MacKit；开关名称随功能状态更新。

应用卸载的页面、服务、扫描/权限重置/删除代码、模块标识、相关测试及工程引用均已移除。完整磁盘访问入口和权限数据库探测也已删除。不会删除用户此前生成的本地操作记录。

## 验证

- Xcode 27.1 / macOS 27 SDK / deployment 14.0：签名 Debug 构建成功。
- 8 项核心测试通过：Esc 状态、剪贴板所有权、角标过期、原子文件替换监听、停止标记及旧状态兼容。
- 6 项隔离快捷键持久化检查通过：首次默认、分别清空、同时清空、重新录制和无效配置恢复。未更改用户快捷键配置。
- 主程序及扩展仍采用同一 Personal Team 的 Apple Development 证书。
- 0.3 用户已确认隔离其他扩展后显示角标，恢复后反馈似乎也正常；未继续变更其他扩展。

## 待人工验证

清空快捷键后立即失效、重启保持未设置、重新录制恢复；菜单栏项目及状态；右对齐布局；透明橙色剪刀的可见性。macOS 14、15、27 和 Intel 尚未实机验收。

访达对某些目录及多扩展共存有限制，详见 [角标诊断](BADGE-DIAGNOSTICS.md)。SDK 构建不替代实机兼容性验证。

最终重载验收：通过界面点击重载后，旧扩展 PID 已消失，只剩新的扩展实例；签名校验成功。对系统暂停后无法处理停止通知的实例，使用当前用户 UID 与本应用内精确可执行路径双重匹配后发送 SIGTERM，不按名称匹配、不结束访达或其他扩展。
