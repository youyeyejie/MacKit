## 边界

- 不宣称“扫描全部文件”。自定义位置、访问限制及不透明归属仍可能遗漏。扫描有深度与 30,000 条目上限，大小计算有单项目 50,000 条目上限；不完整结果明确提示。
- 权限清单没有公开系统枚举 API，只读查询失败会显示未知；不写 TCC 数据库。重置仅调用针对所选应用标识的 tccutil，不全局重置，不保证所有系统授权类型都可清除。
- 系统登录/后台项由 macOS 管理，列出候选并引导设置；不使用全局 resetbtm。系统服务、驱动、系统扩展及共享安装内容需厂商卸载器或系统管理流程，不强删。
- 未实现管理员 helper；系统位置文件无权限时逐项失败并保留，不隐式提权。
- macOS 14、15、27、Intel 未实机验收。SDK 构建不替代兼容性验证。
- Finder 原生传输无可靠事务回调，界面只报告已交给 Finder；取消需重新剪切。待移动会话最长 10 分钟，异常退出后最多等至过期。
- 内存、CPU、能耗尚未正式测量；空闲无全盘扫描，事件监听按功能/前台状态启用。
- 不包含未经同意的新工具功能。
