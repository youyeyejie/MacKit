# 实现与验证状态

版本：v0.8.0，日期：2026-10-28。

## 本轮修改

- 页面正文分组标题统一为 title3.bold，与“一键锁定，安心擦拭”一致。
- 页面内边距 24、卡片内边距 20、卡片间距 18、内容间距 14、设置行高 44；权限、关于与工具页复用同一套组件。
- 关于页恢复为顶部居中显示图标、名称、标语与版本，下方保留信息卡片。
- 清洁说明为“锁定键盘和触控板，解锁需连续按下 5 次 ESC”，移除页面的“如何退出”卡片。实际清洁覆盖层的退出提示保留。
- 音效改用用户提供 MP3 的 0.085–0.235 秒剪刀声；只在开关从关闭切为开启时预览一次，启动和页面出现不触发预览。

## 已有功能

- 完整移除 Finder Sync 扩展 target、源代码、状态文件监听、回执、退出/重载管理、App Group entitlement 和 Info.plist 标识。
- 移除角标配置与诊断 UI、权限页访达扩展入口、安装脚本扩展注册步骤及相关测试。
- 访达剪切成功建立文件会话后播放一次剪切音效。多选只播放一次，未取得文件或文本剪切不播放；粘贴及取消不播放。
- 剪切音效开关默认开启，关闭立即停止声音，偏好使用 UserDefaults 保存。
- 0.15 秒剪刀声 PCM WAV，约 13 KB；NSSound 首次使用才加载，不添加常驻音频引擎或定时器。
- 保留清洁模式、⌘X/⌘V/Esc 文件操作、菜单栏选项和可清空快捷键。

## 验证

- 单 App target 的签名 Debug 构建，无嵌入扩展或共享容器权限。
- 4 项核心测试：Esc 状态机 3 项，剪贴板归属/过期 1 项。
- 6 项隔离快捷键持久化检查。
- 音频资源参数、可解码性与实际打包检查；实际听感和开关效果由用户验证。

macOS 14、15、27 及 Intel 尚未实机验证；跨系统兼容性不以 SDK 编译通过代替。
