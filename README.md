# MacKit

轻量、原生、可扩展的 macOS 工具集。项目名称暂用 MacKit。

当前阶段：产品与技术规划，尚未创建 Swift 工程或实现功能。

首版范围：

- 清洁模式：锁定键盘与触控板、内建显示器显示黑色画面、连续按五次 Esc 解锁。
- Finder 剪切：⌘X 标记待移动文件、图标角标反馈、⌘V 调用 Finder 移动。
- 应用卸载：选择应用、扫描关联文件、审阅后将可处理项目移到废纸篓。
- 后台运行：支持登录后自启动，不显示 Dock 图标，不创建菜单栏图标。

用户已确认：接受 Finder“待移动”角标，优先稳定与轻量；清洁模式必须包含触控板锁定。

完整设计、技术选型、开发顺序、验收要求和待确认候选功能见 [首版开发方案](docs/V1-PLAN.md)。额外功能须经用户同意后才可加入实现范围。
